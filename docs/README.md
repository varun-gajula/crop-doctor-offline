# Project Documentation (docs/)

This directory contains technical documentation, setup guides, licensing audits, and numeric trace references for AI Agri Care.

The most important file is `NUMBER_TRACE.md`, which maps every quantitative performance claim in the project report directly to underlying benchmark data files.

Other essential documentation includes:
- `INSTALL_MODELS.md`: Step-by-step instructions for installing optional ExecuTorch Llama 3.2 1B and Vosk speech models.
- `CREDITS.md`: Licensing and attribution for code, machine learning architectures, datasets, and fonts.
- `DEMO_SCRIPT.md`: Verifiable demonstration script outlining the four-step field diagnostic workflow.
- `REQUIREMENTS.md`: Functional and operational specifications for offline edge execution.
- `REPO_AUDIT.txt`: Pre-submission file hygiene, secrets check, and repository audit log.
