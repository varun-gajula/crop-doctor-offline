## 3. Engineering Hard Rules (H1–H12)

| Rule ID | Rule Summary | Enforcing Mechanism | Verification Method |
| :--- | :--- | :--- | :--- |
| **H1** | No `INTERNET` permission in any build variant. | Stripped manifest; build check. | **proven by:** `benchmarks/permissions_check.txt` (`aapt2 dump permissions app-debug.apk` returns 0 network permissions). |
| **H2** | Never commit datasets, Llama weights (~1.1 GB), keystores, or API keys. | Strict `.gitignore` from commit 1. | **proven by:** `.gitignore` and `git ls-files` audit (0 large files tracked). |
| **H3** | Never invent numbers (accuracy, latency, tokens/s, RAM). | Remove static UI metrics; measure live with timers and Android memory APIs. | **proven by:** `app/src/main/java/com/cropdoctor/ui/ResultScreen.kt` (live latency and runtime memory queried at inference). |
| **H4** | Never invent agronomy. Every treatment cites an official source (ICAR/NIPHM/SAU/KVK/CIB&RC). Doses only with verified quote or "follow the product label". | Strict JSON schema + automated validator script. | **proven by:** `scripts/validate_kb.py`. |
| **H5** | Safety & referral decisions live in pure unit-tested Kotlin code; Llama only explains. | Deterministic rules engine; guardrail interceptor scrubbing dosage hallucinations. | **proven by:** `app/src/test/java/com/cropdoctor/SeverityCalculatorTest.kt`<br>`app/src/test/java/com/cropdoctor/GuardrailFilterTest.kt`. |
| **H6** | Telugu is NEVER generated by Llama; comes from human-verified KB. | Fixed templated assembly for Telugu; Llama Telugu generation blocked. | **proven by:** `app/src/main/java/com/cropdoctor/advisor/ExecuTorchLlamaAdvisor.kt`. |
| **H7** | Stay inside project folder; zero paid cloud. | Self-contained project directory; open-source dependencies. | **proven by:** Project git repository status. |
| **H8** | Emulator development unblocked without phone using Fakes. | `FakeClassifier` and `FakeAdvisor` mocks implementing interfaces. | **proven by:** `app/src/main/java/com/cropdoctor/vision/FakeClassifier.kt`<br>`app/src/main/java/com/cropdoctor/advisor/FakeAdvisor.kt`. |
| **H9** | Zero budget: only free-tier tooling and open-source models. | Open-source toolchain (ExecuTorch, PyTorch, Llama 3.2 Community License). | **proven by:** Toolchain inspection. |
| **H10**| Quota economy on Antigravity free tier. | Batched operations, concise outputs, user-executed heavy tasks. | **proven by:** Phase-by-phase execution log. |
| **H11**| No fake intelligence: label comes ONLY from trained model (`vision.pte`). No hand-written colour, shape rule choosing a label. Soft crop photo warning with "use anyway". "Not sure" if model missing. | Pure ExecuTorch inference; SmartVisualClassifier deleted; soft crop validation. | **proven by:** `app/src/main/java/com/cropdoctor/vision/ExecuTorchClassifier.kt`<br>`app/src/main/java/com/cropdoctor/vision/LeafValidator.kt`<br>`app/src/test/java/com/cropdoctor/LeafValidatorTest.kt`. |
| **H12**| No hardcoded measurements. Live timer and runtime memory on hidden judge screen (long-press on title). | Live metrics calculation; benchmark panel hidden from farmers. | **proven by:** `app/src/main/java/com/cropdoctor/ui/ResultScreen.kt`. |
