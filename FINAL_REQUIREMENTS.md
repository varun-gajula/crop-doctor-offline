## B. Requirements with acceptance tests

### Functional
- **F1 Photo input.** Camera and gallery; leaf, stem, fruit or pest photos are all accepted. Test: photos of each of the four kinds are never hard-blocked (only a soft warning).
- **F2 Diagnosis.** One label from the trained model, its type (disease, pest or healthy), and confidence in words (Sure / Probably / Not sure). Below the cut-off or for non-crop photos: "Can't tell - ask an extension officer", never a guess (H11). Test: accuracy and confusion table on our own 100 field photos; non-crop photos give "Can't tell".
- **F3 Pest handling.** Committed: at least two pest classes (tomato spider mites, maize fall armyworm). The result says "Pest" and gives pest-management steps (monitor, thresholds, biological and cultural control first). Stretch: rice pests from IP102 (academic-use licence only; credit it; never redistribute the images), only after the base 25 pass the real-photo test.
- **F4 Severity and urgency, in code only (H5).** Mild / Moderate / Severe from leaf damage, combined with the farmer's answer to "How much of the field is affected? (a few plants / some / most)". Result: Early warning / Act this week / Act now. Test: unit tests for every combination; same result in all three languages.
- **F5 Treatment and intervention.** Tiers: prevention and field practice, natural and traditional, chemical. The tier opened first depends on urgency. Every item has an official source; doses appear only when verified (H4). Safety line always shown.
- **F6 Region-specific advice.** Regions: Telangana, Andhra Pradesh, Other (general ICAR advice). Each knowledge-base entry names its regional source (PJTSAU, ANGRAU or ICAR) and states a regional difference only when an official source says so; otherwise "same for all regions". Helpline numbers are shown only after verification against official pages.
- **F7 Languages.** Telugu, Hindi, English; identical steps in identical order; switching never loses the result. Telugu text is never generated by Llama. Test: parity tests plus native-speaker sign-off.
- **F8 Advisory (Llama).** Llama 3.2 1B-Instruct via ExecuTorch on the Arm CPU explains the finding using only the structured finding and approved text; output labelled "AI explanation"; guardrail rejects doses, unknown products and contradictions; if memory is low or the guardrail rejects the output, the app shows the knowledge-base text and says so. Hindi explanation allowed only if it passes the 20-case test. Stretch: Llama answers three suggested follow-up questions per case, grounded only on the same text (replaces the keyword chatbot).
- **F9 Extension-worker tools.** Red "Talk to an extension officer" button for severe or uncertain cases (Kisan Call Centre 1800-180-1551). "Save case report" stores crop, finding, type, severity, certainty, region, date, photo and note locally; "Share" uses the Android share sheet. The shared report contains no unverified chemical or dose information.
- **F10 Read-aloud.** A Listen button in all three languages; if the voice is missing the app says "Voice not installed" and how to install it.
- **F11 Early warning.** Mild and moderate results include an early-warning line and "what to watch for in the next days".
- **F12 Fertiliser and irrigation.** Each crop's prevention tier includes sourced irrigation and nutrient practices relevant to the problem (for example avoiding leaf wetness, balanced nitrogen), only where an official source says so.

### Non-functional
- **N1 Offline.** No INTERNET permission in any build; the whole demo runs in airplane mode. Evidence: `aapt2 dump permissions` output and a screen recording.
- **N2 Memory (6 GB phone, H15).** Peak PSS at most 2.5 GB with Llama loaded and 500 MB without. Measured on a real 6 GB arm64 phone; plus a 6 GB emulator run for layout only.
- **N3 Speed.** Shutter to result within 1.5 s; cold start within 2 s; under 2% janky frames; Llama time to first token and tokens/s logged. Release build with Baseline Profile.
- **N4 Safety.** No fake diagnosis; no invented numbers (H3); calibrated confidence; a written hazard list (for example: wrong disease shown, wrong chemical advised, farmer over-trusts AI) with the mitigation for each.
- **N5 Usability.** Three non-engineers (ideally one farmer) understand the advice in under 60 seconds without help.
- **N6 Privacy.** No data leaves the phone unless the user shares a report. No analytics or network libraries.
- **N7 Licences.** "Built with Llama" and the Llama 3.2 licence notice; dataset credits (CC BY sources credited; IP102 academic-use note); Noto fonts (SIL OFL).
- **N8 Engineering quality.** Unit tests green; debug and release builds pass; version pins for ExecuTorch recorded; a clean clone of the repo builds the APK by following the README.

### Deliverables
- **D1** Public GitHub repo (no datasets, no Llama files, no keys).
- **D2** APK attached to a GitHub Release.
- **D3** Demo video: core demo under 60 seconds in airplane mode, showing (1) photograph, (2) label and severity, (3) language switch with the same advice, (4) uncertainty and extension-officer route.
- **D4** Technical report with these sections: 1 problem and users; 2 architecture; 3 vision pipeline (data and licences, model, training, calibration, real-photo accuracy, limits); 4 advisory pipeline (Llama via ExecuTorch, prompt, guardrail, knowledge base and sources); 5 languages and review; 6 safety and hazard list; 7 measurements on an Arm phone (RAM, latency, tokens/s, size); 8 limitations; 9 out-of-scope; 10 reproducibility and licences. Measured numbers only.

## C. Out of scope (stated openly in the report)
Post-harvest loss reduction, voice input (speech recognition), Hailo and Raspberry Pi, Kannada and Tamil, fine-tuning Llama, cloud sync, crops beyond the five.

## D. Decisions recorded
1. Severity comes from code only; the model has no severity head.
2. Regions are Telangana, Andhra Pradesh and Other. Karnataka and Tamil Nadu are removed from the picker because we have no Kannada or Tamil text.
3. Chilli class 13 stays UNVERIFIED and out of training until a human confirms its cause.
4. Committed pests: two. Stretch pests: rice, from IP102, after the base 25 pass.
5. Case-report sharing never includes unverified chemical details.
